# おさいふ

毎月の支払いをカレンダーと通知でお知らせしつつ、収入・支出と財布（口座）の残高を管理する家計簿 Web アプリ（PWA）。

## 機能

- **ホーム**：今月の収支・予算の残り／今月の支払い（期日・超過表示、ワンタップで「支払済」）／財布の残高／支出の内訳
- **カレンダー**：日ごとの収支と支払い予定をドット表示。日付タップで明細、その日に記録
- **履歴**：月ごとの記録を日付別に表示。支出・収入・振替で絞り込み、タップで編集
- **財布**：現金・口座・カードの残高、財布間の振替、設定
- **記録（＋ボタン）**：支出／収入／振替。金額→カテゴリ→財布の順で最短入力
- 左右スワイプで月を切替、ダークモード対応

## 通知について

- **アプリ内通知**：設定でオンにすると、アプリを開いた時に「期日が近い／過ぎた未払いの支払い」を1日1回通知します。Web の仕様上、アプリを開いていない間は通知されません。
- **スマホのカレンダーに登録（推奨）**：設定の「書き出し」で `.ics` を出力し、iPhone / Google カレンダーに取り込むと、支払日の指定日前 9:00 に OS のリマインダーとして確実に通知されます。

## データ

すべて端末のブラウザ（localStorage）に保存され、外部には送信しません。機種変更やブラウザのデータ削除に備え、設定の「バックアップ → 保存」で JSON を書き出してください。

## 使い方

ビルド不要の静的ファイルです。GitHub Pages などで公開し、スマホで開いて「ホーム画面に追加」するとアプリとして使えます。

```sh
python3 -m http.server 8000   # http://localhost:8000
```
