# おさいふ

毎月の支払いをカレンダーと通知でお知らせしつつ、収入・支出と財布（口座）の残高を管理する家計簿 Web アプリ（PWA）。

## 機能

- **ホーム**：今月の収支・予算の残り／今月の支払い（期日・超過表示、ワンタップで「支払済」）／財布の残高（引き落とし口座の残高不足を警告）／支出の内訳
- **カレンダー**：日ごとの収支と予定をドット表示。日付タップで明細、その日に記録。予定は日付順／口座別（小計つき）で切り替え
- **履歴**：月ごとの記録を日付別に表示。支出・収入・振替で絞り込み、タップで編集
- **財布**：現金・口座・クレジットカード、財布間の振替、設定
- **記録（＋ボタン）**：支出／収入／振替。金額→カテゴリ→財布の順で最短入力
- 左右スワイプで月を切替、ダークモード対応
- **予定**：支払い・収入を、頻度（毎月／2か月／3か月／半年／年1回）・起点の月・支払日・支払い元・お知らせ日で登録。金額が毎月変わるもの（電気代など）は記録時に確定
- **クレジットカード**：締め日・引き落とし日・引き落とし月・引き落とし口座を設定すると、利用額から引き落とし日ごとの金額を自動計算して予定に表示。「引落」で口座からカードへの振替を記録
- **明細の取り込み**：銀行・カードのCSV（UTF-8／Shift_JIS）を読み込み、取り込み先の財布・列の対応・行を確認して取り込み。同じ明細の二重取り込みは自動で除外、カテゴリは過去の記録とキーワードから推定
- CSV 書き出し（Excel / Google スプレッドシート用、BOM 付き UTF-8）
- レシート読み取り：支出の記録で写真を選ぶと、合計金額・日付・店名・カテゴリを自動入力（端末内で文字認識。画像は送信しない。初回は日本語の認識データ（数MB）を取得）
- ログインとクラウド同期（任意）：Google／メールでログインして複数端末のデータをそろえる（下記の設定が必要）

## 通知について

- **アプリ内通知**：設定でオンにすると、アプリを開いた時に「期日が近い／過ぎた未払いの支払い」を1日1回通知します。Web の仕様上、アプリを開いていない間は通知されません。
- **スマホのカレンダーに登録（推奨）**：設定の「書き出し」で `.ics` を出力し、iPhone / Google カレンダーに取り込むと、支払日・カードの引き落とし日の指定日前 9:00 に OS のリマインダーとして確実に通知されます（隔月・年1回の予定にも対応）。

## データ

すべて端末のブラウザ（localStorage）に保存されます。クラウド同期を設定・ログインした場合のみ、自分の Firebase プロジェクトにも保存されます。機種変更やブラウザのデータ削除に備え、設定の「バックアップ → 保存」で JSON を書き出してください。

## クラウド同期の設定（任意）

1. [Firebase コンソール](https://console.firebase.google.com/)でプロジェクトを作成（無料の Spark プランで可）
2. 「Authentication」→「始める」→ ログイン方法で **Google** と **メール／パスワード** を有効化（使う方だけでも可）
3. 「Authentication」→「設定」→「承認済みドメイン」に公開先（`osaifu.birdman-studio.com`）を追加
4. 「Firestore Database」→「データベースを作成」（本番環境モード）→「ルール」に [`firestore.rules`](firestore.rules) の内容を貼り付けて公開
5. 「プロジェクトの設定」→「マイアプリ」でウェブアプリを追加し、表示された `firebaseConfig` を [`config.js`](config.js) の `window.OSAIFU_FIREBASE` に貼り付けてコミット
6. アプリを開くとログイン画面が出ます。Google、またはメールアドレスとパスワード（「新規登録」）でログインしてください

`firebaseConfig` の値は公開されても問題ありません（アクセスはルールでログインした本人のデータに限定）。同期は1件ずつ比較し、同じ記録を複数端末で同時に変更した場合は後から同期した端末の内容が残ります。

### ログインの動き

- Firebase を設定すると、初回起動でログイン画面が出ます。「ログインせずに使う」を選ぶと、これまでどおり端末内だけで使えます（設定画面からいつでもログインできます）。
- [`config.js`](config.js) の `window.OSAIFU_REQUIRE_LOGIN = true` にすると、ログインしないと使えなくなります。
- ログアウトすると、この端末のデータは削除されます（クラウドの記録は次回ログインで復元されます）。
- 別のアカウントのデータが端末に残っている時は、確認するまで混ぜません。
- Apple でサインインは含みません（Apple Developer Program への加入が必要なため）。

## 口座連携について

銀行・カード会社の口座へ直接つなぐ連携（口座連携）は入れていません。個人のアプリが他人の口座情報を取得するには、電子決済等代行業の登録、または登録済みの事業者（Moneytree、Finbee など）との契約が必要で、ID やパスワードを預かる方法は安全面・規約面で避けるべきためです。

代わりに、各社のサイトからダウンロードできる明細 CSV を「財布 → 明細の取り込み」から読み込めます。Money Forward ME や Zaim などで連携している場合は、そこから書き出した CSV も取り込めます。

## 使い方

ビルド不要の静的ファイルです。GitHub Pages で `https://osaifu.birdman-studio.com/` に公開し、スマホで開いて「ホーム画面に追加」するとアプリとして使えます。

### 公開設定（GitHub Pages とドメイン）

1. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にする
2. 同じ画面の Custom domain に `osaifu.birdman-studio.com` を入力して Save（リポジトリ直下の `CNAME` と同じ値）
3. DNS に `osaifu` の CNAME（値 `b-w-hiroki.github.io`）を登録する
4. DNSの確認が済んだら「Enforce HTTPS」にチェックを入れる

データはURLごとにブラウザに保存されます。公開URLを変えると以前のデータは引き継がれないので、変更時は「バックアップ」で保存・復元してください。

```sh
python3 -m http.server 8000   # http://localhost:8000
```

## テスト

Playwright で主要な操作（記録・振替・定期支払い・.ics / CSV 書き出し・バックアップ復元・レイアウト崩れ）を検証します。PR ごとに GitHub Actions で自動実行されます。

```sh
npm install
npx playwright install chromium
npm test
```

## 広告（i-mobile）

広告枠は用意済みで、スポットを設定するまでは何も表示・通信しません。i-mobile の審査通過後、`ads.js` の `IMOBILE` に `pid` と各スポットの SP / PC 用 `mid` / `asid` を入れると表示されます。

| スポット | 場所 |
|---|---|
| `lp` | トップページ（LP）のフッター直前 |
| `login` | ログイン画面のボタン群の下 |
| `history` | 履歴タブの末尾 |

- インラインバナーのみ（オーバーレイは使わない）。SP / PC 用タグは端末で出し分け
- 広告が実際に描画されたときだけ枠を表示（在庫切れ・ブロック時は空枠を出さない）
- 規約・プライバシーポリシーに広告配信（i-mobile）の記載あり
